# Salinan rujukan migrasi

Migrasi yang dieksekusi berasal dari `../../scripts/migrations/`; berkas SQL di folder ini adalah salinan untuk dibaca. Jika sumber berubah, perbarui salinannya dan jalankan `npm test` yang memeriksa kesamaan nama dan isi. Jangan menjalankan salinan ini sebagai sumber migrasi kedua.
