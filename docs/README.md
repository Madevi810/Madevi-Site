# Dokumentasi Madevi

Ikuti urutan ini dari memahami aplikasi sampai menyiapkan operasi. Panduan layanan dapat dibaca dan disiapkan saat aplikasi masih lokal.

| Urutan | Bacaan | Hasil yang dituju |
| --- | --- | --- |
| A. Pahami Madevi | [README](../README.md) dan [fundamental proyek](fundamental.md) | Kenali tujuh ruang, fungsi yang tersedia, struktur kode, dan prioritas. |
| B. Jalankan lokal | [Panduan lokal](lokal.md) | Komputer, database uji, migrasi, akun demo dan pemeriksaan dasar siap. |
| C. Kenali kebutuhan | [Persiapan online](online.md#yang-perlu-disediakan) | Ketahui layanan wajib, fitur opsional, dan pekerjaan yang dapat menunggu. |
| D. Pilih jalur | [Perbandingan dua jalur](online.md#dua-jalur) | Tentukan pilihan sementara, tanggung jawab, batas dan anggaran. |
| E. Siapkan layanan | [Langkah tiap layanan](siapkan-layanan.md) | Dapatkan URI, origin, TLS, serta pengaturan email dan Google bila dibutuhkan. |
| F. Hubungkan dan uji | [Environment dan migrasi](online.md#2-isi-environment-dari-sumber-yang-tepat) serta [uji admin dan alur](online.md#5-buat-admin-dan-uji-alur) | Cocokkan nilai, jalankan migrasi, dan coba alur dari lingkungan tujuan. |
| G. Jalankan online | [Jalankan dan periksa aplikasi](online.md#4-jalankan-aplikasi-dan-periksa-layanan) serta [checklist](../ops/deploy-checklist.md) | Verifikasi sebelum dan sesudah aktivasi staging, lalu nilai kesiapan produksi. |
| H. Pelihara dan pindah | [Operasional](operasional.md) dan [Jika Saya Mengganti Layanan atau API](ganti-layanan.md) | Siapkan backup, restore, monitoring, pergantian provider dan rollback. |
