## Bukti pengujian

- Rangkaian integrasi PostgreSQL 18 dengan `MADEVI_TEST_BUILD=1`, `MADEVI_TEST_LOAD=1` dan `MADEVI_VISUAL_CHECK=1` lulus untuk aplikasi, build, smoke runtime, browser Chromium, dan aksesibilitas yang tercakup tes. Data, akun, dan SMTP memakai fixture sintetis.
- Browser menguji formulir lampiran, kirim langsung, jadwal dan batal, perbandingan dan pemulihan pengaturan, dukungan dua arah, serta pemulihan tampilan monitoring dari respons 503 simulasi. Admin dengan sesi MFA mengajukan backup dan restore melalui browser. UI juga menahan pilihan rilis yang skemanya tidak cocok. Akun biasa dan sesi admin tanpa MFA ditolak.
- Worker lokal memakai klien PostgreSQL 18 dari container uji. Dua worker tidak menjalankan pekerjaan yang sama. Unduhan menghasilkan arsip AES-GCM. Checksum migrasi dan jumlah lampiran per format PDF, TXT, dan CSV cocok setelah restore ke target uji. Kunci salah, artefak rusak, konfirmasi salah, dan target terisi ditolak.
- Pengujian worker membuat sampel heartbeat kedaluwarsa, lalu membuktikan worker baru mengembalikan status segar dan mencatat kejadian pulih.
- Role migrasi, runtime, dan backup diperiksa dengan role non-superuser. Bootstrap admin tunggal tetap menolak pembuatan admin kedua. Uji CLI pemulihan dan tes unit melengkapi alur yang tidak memerlukan browser.
- Typecheck serta 26 tes unit lulus. Enam screenshot README diambil dari aplikasi dengan PostgreSQL lokal dan diperiksa secara visual.
- Katalog, kompatibilitas skema, dan pemulihan profil diuji dengan simulasi batas restart. `docker compose config` lulus pada profil sintetis dengan override tanpa env produksi. Pergantian container di host tujuan dan verifikasi layanan penyedia belum dijalankan. Workflow CI diperbarui, dengan bukti di atas berasal dari pelaksanaan lokal.

## Keputusan dan batas

Default tetap memakai PostgreSQL yang sama untuk data dan antrean. Worker menjalankan pekerjaan terstruktur dari host. Proses web memakai mount baca-saja bila unduhan diaktifkan. Restore memulihkan target kosong terpisah. Antrean dari snapshot ditutup pada target supaya pekerjaan lama tidak berjalan otomatis.

Profil host berisi sumber daya CPU dan memori. Environment, kunci, DNS, koneksi database dan proxy diatur oleh operator. Rollback rilis memerlukan katalog image lokal, daftar skema cocok, dan backup baru. Pergantian rilis tidak mengubah database. [Persiapan host dan alur admin](operasi-admin.md)

Monitoring mengukur respons akhir route yang diberi label, status probe, dan sampel worker. Data dari penyedia SMTP/OAuth, jaringan staging, dan pergantian container pada host tujuan belum diperiksa. Akun layanan, deployment, DNS, dan secret nyata tidak diubah. Materi tujuh ruang dan sistem sosial lanjutan berada di luar pekerjaan ini.
