# Spesifikasi default Madevi

Madevi adalah proyek yang saat ini dimiliki dan dikendalikan satu pemilik. Kepemilikan mencakup repositori dan kendali atas layanan. Dalam aplikasi, satu admin utama memegang kewenangan pengelolaan. Akun pengguna website mengikuti pendaftaran email yang terbuka saat SMTP siap, atau Google untuk pengguna biasa jika diaktifkan. Keduanya independen dari kepemilikan proyek.

Jalur standar adalah Node.js di container Docker Compose, satu PostgreSQL 18, dan Caddy pada host yang menyediakan HTTPS. Penyedia untuk host, PostgreSQL, domain dan SMTP belum dipilih. SMTP dan Google bisa disiapkan ketika fitur masing-masing dibutuhkan. Semua layanan tujuan masih memerlukan konfigurasi dan uji milik pemilik.

API internal adalah route `/api/*` aplikasi. Integrasi eksternal yang diperlukan oleh kode sekarang ialah PostgreSQL, SMTP bersyarat, dan Google bersyarat. Pemrosesan media berjalan di aplikasi. GitHub berfungsi untuk kode dan CI. Tidak ada pembayaran, pencarian eksternal, penyimpanan cloud, atau monitor aktif yang harus disediakan untuk startup.

Baca [aktivasi default](aktivasi-default.md) untuk menjalankan jalur standar atau [pergantian layanan](ganti-layanan.md) jika kontraknya berbeda.


## Operasi host dan alarm opsional

Systemd menjalankan worker pesan, worker operasi, pemeliharaan dan alarm dalam tugas terpisah pada host Compose. Ambang alarm dan penerimanya berasal dari environment host. Kanal memakai konfigurasi SMTP Madevi, probe loopback, status privat di disk dan pengukuran PostgreSQL bila tersedia. Retensi database mendukung mode pemeriksaan dan batch. Backup rutin tetap opsional dan memakai enkripsi yang sama dengan panel. Verifikasi salinan dan restore ke target kosong. [Panduan systemd](../ops/systemd/README.md), [API](api.md)
