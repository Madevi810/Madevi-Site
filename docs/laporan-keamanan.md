# Hasil penguatan keamanan Madevi

Dasar pemeriksaan adalah Madevi V0.0.0.22 pada commit `6ff56c7`. Pembaruan ini tercatat pada [Madevi V0.0.0.23](../CHANGELOG.md). Migrasi `007_account_security` menambah waktu aktivitas sesi, bukti perubahan email, pelindung peran, tinjauan publikasi dokumen dan pencabutan sesi saat identitas berubah. Migrasi terdahulu dipertahankan. [Changelog](../CHANGELOG.md)

## Batas dan tindak lanjut aktivasi

Cakupan ASVS merujuk kontrol autentikasi, sesi, otorisasi, berkas, konfigurasi, perlindungan data dan pencatatan yang terdampak. Hasil ini adalah bukti pengujian terarah. [ASVS 5.0.0](https://github.com/OWASP/ASVS/tree/v5.0.0_release)

Mirror pertama Trivy mengembalikan HTTP 403. Database advisory resmi berhasil diunduh dari GHCR. Pemindaian awal menunjukkan empat paket PAM Debian untuk CVE-2025-6020 serta enam temuan pada `brace-expansion` dan `undici` yang dibundel npm bawaan image. PAM diperbarui dari `1.5.2-6+deb12u2` ke `1.5.2-6+deb12u3` melalui Debian Security. npm dan package manager lain dikeluarkan dari image runtime. Migrasi, kesiapan role web, non-root, cache tulis terbatas dan endpoint kesehatan lulus pada image pengganti. [Debian Security Tracker](https://security-tracker.debian.org/tracker/CVE-2025-6020)

Pemindaian ulang Trivy pada 27 November 2026 menemukan nol temuan HIGH/CRITICAL yang memiliki perbaikan pada image uji. Filter tersebut menjadi batas hasil pemindaian. Audit npm dan aturan Semgrep memeriksa cakupan lain secara terpisah. Workflow GitHub sudah dikonfigurasi; hasil yang dicatat berasal dari executor lokal.

Kredensial PostgreSQL, rahasia autentikasi, SMTP, Google opsional, proxy, backup dan retensi tetap diisi oleh pemilik saat aktivasi. Operator perlu menguji koneksi staging, hak role, akses origin/proxy, pemulihan cadangan di luar host, dan penerimaan alarm SMTP dengan konfigurasi tujuan.
